# SKIN 기능명세서

## UI 사용자 흐름 중심 명세서

탭 분류

- 하단 네비게이션
    
    ```java
    [HOME] [TODO] [REPORT] [MY]
    
    ※ 도메인 분리: home / todo / report / mypage
    ※ 온보딩(ONB-01~05)은 탭 밖 진입 플로우
    ※ 피그마 Tab Bar 컴포넌트는 현재 [홈][스캔][리포트][설정] → 명칭 동기화 필요
    ```

HOME

```java
HOME  (HOME-01 ~ 09)
 ├ 날짜 및 웰컴멘트                              HOME-01
 ├ 어젯밤 수면 통역 카드 -> REPORT 일간           HOME-02
 ├ 오늘의 피부 예보 (장벽·유분·다크서클·칙칙함)   HOME-03
 ├ 게이미피케이션 -> 캐릭터 클릭 -> [논의 필요]   HOME-04
 ├ 셀피 검증 CTA
 │   ├ 촬영                                      HOME-05
 │   ├ 분석 (LLM 지표 산출)                      HOME-06
 │   ├ 결과 (예보 vs 실측)                       HOME-07
 │   └ "오늘의 스킨 처방" -> TODO 탭
 ├ 개인 모델 학습 (가중치 보정)                   HOME-08
 └ 예보 적중률 · 연속 검증 배너                   HOME-09
```

TODO

```java
TODO  (TODO-01 ~ 07)
 ├ 날짜 및 요약 멘트                              TODO-01
 ├ 리포트 기반 행동 추천 (추천 엔진)              TODO-02
 │   ├ 오늘은 피하세요                           TODO-03
 │   └ 오늘은 이렇게                             TODO-04
 ├ TODO 리스트 체크·완료 처리                     TODO-05
 ├ TODO 추가항목 선택   [와이어프레임 없음]       TODO-06
 └ 저녁 수면 가이드 (취침 목표·시나리오 비교)     TODO-07
```

REPORT

```java
REPORT  (REP-01 ~ 12)
 ├ 탭 네비게이션 (일간·주간·월간·종합)            REP-01
 ├ 일간 ├ 인사이트 · 오늘의 액션                  REP-02
 │      ├ 수면 단계 타임라인                     REP-03
 │      ├ 수면 관련 수치 (요약 통계)             REP-04
 │      └ 오늘의 피부 지표 (전일 대비)           REP-05
 ├ 주간 ├ 수면 점수 추이                         REP-06
 │      └ 피부 직결 원인 및 영향도               REP-07
 ├ 월간 └ 주차별 수면 점수표                     REP-08
 ├ 종합 ├ 종합 판단 (트리아지)                   REP-09
 │      ├ 앱이 도와준 / 클리닉 필요 항목         REP-10
 │      └ 엠레드 클리닉 상담 연결 -> 웹          REP-11
 └ 내 모델 — 일반 vs 개인화  [탭 미배정]          REP-12
```

MY

```java
MY  (MY-01 ~ 05)
 ├ 프로필 · 모델 신뢰도 요약                      MY-01
 ├ 데이터 연결 상태 (애플 건강 앱)                MY-02
 ├ 알림 설정 (아침 예보 · 취침 알림)              MY-03
 ├ 프라이버시 · 데이터 관리                       MY-04
 └ 정보 (버전 · 문의 · 약관)                      MY-05

ONBOARDING  (ONB-01 ~ 05) — 탭 밖
 시작 화면 -> 개인정보 동의 -(no)-> 앱 종료
              └(yes)-> 수면 데이터 연결 -> 랜딩(HOME)
```
